Ningaui bookmarklet

Everything the extension does — the agent loop, the sandbox, the action queue, the earned-autonomy policy — packed into one self-contained bookmark. No install, no permissions prompt: click it on any page you want the agent on.

Drag this button to your bookmarks bar:

loading the packed bookmarklet…

If dragging is blocked: create a bookmark for any page, then paste the full URL into its address field.

This page loads ningaui-bookmarklet.url.txt — the packed bookmark — and the readable bundle it unpacks is ningaui-bookmarklet.js. Running limits of this mode — strict-CSP sites, CORS on API calls, per-site storage, and page-context trust — are documented in docs/bookmarklet.md. For full-strength use (host permissions, Chrome's built-in model, isolated context), install the extension: bundles on the releases page.
