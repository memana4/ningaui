# Code of Conduct

Be decent. Specifically:

- Assume competence. Explain your reasoning rather than asserting conclusions.
- Critique the work, not the person. "This breaks on Firefox because…" is useful;
  "this is amateur" is not.
- No harassment, slurs, or personal attacks, in issues, pull requests, commit
  messages, or code comments.
- Disagreement is welcome. Bad faith is not.

Violations can be reported to the maintainers through a private security advisory
or a direct message on the platform hosting the repository. Maintainers may edit,
lock, or remove contributions that violate this, and will say why.

This is a small project maintained in spare time. Patience is part of the deal.
